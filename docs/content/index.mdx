![tSync](/assets/tSync/banner.jpg)

GTA runs every vehicle's light pattern off a timer that starts when its siren
comes on. Two cars that lit up a second apart flash a second apart for as long
as they are lit, and nothing in the game ever pulls them together.

tSync restarts those timers together.

<Callout type="info" title="This is for non-ELS lighting">
  tSync works by restarting GTA's own light timer, so it only affects vehicles
  that GTA is lighting — vanilla, [Luxart Vehicle
  Control](https://github.com/TrevorBarns/luxart-vehicle-control), Ultimate
  Lighting Controller, and the rest of the non-ELS world. A script that draws
  its own lights has no engine timer behind them to restart.
</Callout>

## What it does

- Re-times vehicles **whose lights are already on**, within range of each player
- Leaves vehicles another lighting script owns alone
- Needs no configuration to work

It does not switch lights on or off, change a pattern, a colour or a flash rate,
or replace a lighting controller — it has no UI, no keybinds and no patterns.

## Requirements

| | |
| --- | --- |
| tLib | **v1.0+**, free — [download](https://github.com/tommy141x/tLib/releases) |
| Framework | None, and none is needed |
| Database | None |
| OneSync | Not required |

## Cost

One pass every `intervalMs` on each client, walking the vehicles within
`radius`. There is no server component and no network traffic at all — see
[How it works](/docs/tSync/usage#how-it-works).
