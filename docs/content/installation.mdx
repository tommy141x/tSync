One dependency, no database, no NUI, no build step.

## 1. Install tLib first

tSync declares `dependency 'tLib'` and `tlib_min_version '1.0'`. Download it from
[the releases page](https://github.com/tommy141x/tLib/releases).

Starting tSync without tLib stops it at load with a line naming tLib. That is the
gate working: the alternative is a missing module surfacing as `attempt to index a
function value` halfway down a script.

## 2. Drop the folder in

Into `resources/`, named exactly `tSync`. No spaces, no `-main` suffix from a
GitHub zip — the folder name is the resource name.

## 3. Add it to server.cfg

```cfg
ensure tLib
ensure tSync
```

**After tLib.** tSync reads `tlib.config` at load to validate its own
configuration; starting first means that validation does not run.

## 4. Restart

`ensure tSync` in the server console, or txAdmin → Resources → tSync → Restart.

A healthy boot prints the tSync banner with one row:

```
Syncing   class 18 every 5000ms within 150m
```

That row is the **configuration**, not a count of work done — the work is
entirely client-side and the server never runs a pass.

## Confirming it works

The honest check is in-game, with two lit vehicles.

1. Park two emergency vehicles side by side and switch both sets of lights on a
   second or two apart, so they are visibly out of step.
2. Wait for `intervalMs` — five seconds by default.
3. They should snap into step and stay there.

To see the mechanism rather than the result, run `tsync_diag` in the client
console (F8):

```
tSync 1.0.0 — tLib 1.0.0
every 5000 ms, within 150 m, classes 18
deferring to: nothing running
last pass re-phased 2 vehicle(s), 1.4 s ago
```

A **count of zero with vehicles clearly lit around you** is the useful failure:
they are failing a selection rule rather than the reset not working.
[Troubleshooting](/docs/tSync/troubleshooting) walks the four rules.

## Upgrading

Unzip over the top. `config.lua` ships with its defaults and is the only file you
edit, so an upgrade replaces it — keep a copy if you have changed anything.
